# Система управления курьерами

## Назначение
Приложение предназначено для автоматизации работы службы доставки. Оно позволяет управлять курьерами, отслеживать их статус, назначать заказы и контролировать выполнение доставок.

## Целевая аудитория
- Менеджеры и диспетчеры служб доставки
- Администраторы курьерских служб
- Владельцы небольших логистических компаний

## Предметная область
Курьерская доставка — это процесс перемещения товаров или документов от отправителя к получателю. В системе выделяются следующие ключевые понятия:
- Курьеры, которые выполняют доставки
- Заказы, которые необходимо доставить
- Статусы заказов (новый, в пути, доставлен)
- График работы курьеров

## Основные сущности
- **Курьер**: имя, фамилия, телефон, транспорт (автомобиль/велосипед/пешком), статус (свободен/занят/не работает), зона обслуживания
- **Заказ**: номер заказа, адрес доставки, контакт получателя, вес, стоимость, статус (новый/в пути/доставлен/отменен)
- **Диспетчер**: сотрудник, который назначает заказы курьерам
- **Зона доставки**: район или территория, за которую отвечает курьер

## Основные функции
1. **Добавление нового курьера** — регистрация курьера в системе с указанием всех данных
2. **Назначение заказа курьеру** — выбор свободного курьера и назначение ему заказа
3. **Изменение статуса заказа** — обновление статуса (например, "в пути" → "доставлен")
4. **Просмотр списка курьеров** — вывод всех курьеров с их текущим статусом и количеством заказов
5. **Проверка доступности курьера** — анализ, может ли курьер взять новый заказ (учитывая статус и зону)

## План развития
На следующих этапах планируется:
1. **ПР3 (ООП)**:
   - Создать классы Courier, Order, Dispatcher
   - Реализовать методы для работы с объектами
   - Добавить наследование (например, разные типы курьеров)

2. **ПР5-9 (Django)**:
   - Разработать веб-интерфейс
   - Подключить базу данных (PostgreSQL)
   - Создать модели на основе сущностей
   - Реализовать CRUD операции через админ-зону и веб-страницы

3. **ПР10-11 (Пользователи и API)**:
   - Добавить аутентификацию (диспетчеры, менеджеры)
   - Создать REST API для интеграции с мобильным приложением курьеров
   - Настроить права доступа

4. **ПР13-15 (Тестирование и Docker)**:
   - Написать тесты для основных функций
   - Контейнеризировать приложение
   - Настроить CI/CD
